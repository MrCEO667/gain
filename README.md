# Gain

**Карманный голосовой компаньон без экрана. Думаешь на ходу, а агенты в это время работают на твоём компьютере.**

> Раньше проект назывался *Peripatos* (греч. περίπατος) — «прогулка». Так называли школу Аристотеля, где думали и спорили на ходу.

---

## Идея в одном абзаце

Маленький гаджет на брелоке, на шее или на запястье. У него нет экрана и нет динамиков. Звук идёт через наушники с костной проводимостью, поэтому уши остаются открытыми и ты слышишь мир вокруг. Общение с устройством только голосом: внутри живёт ИИ-«архитектор», который разговаривает с тобой, спорит, помогает развивать мысль и по ходу разговора запускает агентов. Они пишут и собирают код, готовят презентации и визуализации прямо на твоём компьютере. Когда ты возвращаешься к столу, всё уже готово и ждёт, чтобы ты посмотрел глазами.

## Главный цикл

```
Мысль на прогулке  →  разговор с архитектором  →  агенты работают на компьютере  →  ты садишься и смотришь результат
      (голос)              (спор, выводы)              (код, слайды, графики)              (одна страница-сводка)
```

Суть проекта — **разделить мышление и исполнение**. Думать лучше вдали от экранов, вслух и в движении. Смотреть и проверять лучше за большим экраном. Устройство связывает эти два режима.

## Принципы

1. **Никакого экрана на устройстве.** Глаза отдыхают. Визуальное — только по требованию: на телевизор, на компьютер или ссылкой в Telegram.
2. **Голос — основной интерфейс.** Говоришь, а не печатаешь. Пальцы не устают, мысль идёт быстрее.
3. **Спарринг, а не поддакивание.** Ассистент задаёт неудобные вопросы и возражает. Это второй голос в диалоге, а не эхо.
4. **Узкий фокус.** Голос, Telegram, оплата, агенты на компьютере. Всё остальное делается на компьютере. Humane погорел, пытаясь заменить всё сразу.
5. **Настоящие предохранители.** Необратимые действия подтверждаются отпечатком пальца или паролем, а не голосовым «да».
6. **Работает и без сети.** Локальный мозг на устройстве для самолёта и мёртвых зон, плюс спутниковая связь через обычный LTE-модем.

## Что устройство умеет и чего не умеет

| Умеет | Не умеет (и не должно) |
|---|---|
| Разговаривать, рассуждать, спорить, помогать с идеями | Показывать что-либо на себе |
| Запускать агентов на твоём компьютере | Заменять компьютер для визуальной работы |
| Читать и писать в Telegram, слушать и отправлять голосовые | Работать с другими мессенджерами (осознанно) |
| Звонить по сотовой связи (eSIM) | Воспроизводить звук без наушников |
| Платить картой по NFC | Ставить приложения из стора |
| Выводить картинку на телевизор по запросу | |
| Работать офлайн и через спутник | |
